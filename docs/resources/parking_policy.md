# turbonomic_parking_policy (Resource)

Manages a Turbonomic parking policy. Parking policies define rules for automatically stopping (parking) and starting cloud workloads on a schedule to reduce costs. Reference a timespan schedule UUID from the turbonomic_timespan data source.

## Example Usage

```terraform
data "turbonomic_timespan" "office_hours" {
  display_name = "Office Hours"
}

resource "turbonomic_parking_policy" "dev_vms" {
  display_name        = "Park Dev VMs Outside Office Hours"
  level               = "ACCOUNT"
  restrict_unparkable = false

  attach_schedule {
    timespan_schedule_uuid = data.turbonomic_timespan.office_hours.timespans[0].uuid
  }

  criteria_list {
    filter_type = "vmsByName"
    exp_type    = "RXEQ"
    exp_val     = "^dev-"
  }
}

resource "turbonomic_parking_policy" "global_weekend" {
  display_name        = "Global Weekend Parking"
  level               = "GLOBAL"
  priority            = 10
  restrict_unparkable = true

  criteria_list {
    filter_type = "vmsByTag"
    exp_type    = "EQ"
    exp_val     = "env:nonprod"
  }
}
```

## Schema

### Required

- `display_name` (String) Human-readable name of the parking policy.
- `level` (String) Scope level at which the policy applies: GLOBAL, CLOUD_PROVIDER, ACCOUNT, RESOURCE_GROUP, DATACENTER, or TARGET.

### Optional

- `attach_schedule` (Attributes) Timespan schedule to attach to this parking policy. Use the turbonomic_timespan data source to look up the UUID. (see [below for nested schema](#nestedatt--attach_schedule))
- `criteria_list` (Attributes List) List of filters to select the entities this parking policy applies to. (see [below for nested schema](#nestedatt--criteria_list))
- `priority` (Number) Priority for conflict resolution when multiple policies apply to the same entity. Lower number = higher priority.
- `restrict_unparkable` (Boolean) When true, entities matched by this policy cannot be manually unparked outside the schedule window.

### Read-Only

- `id` (String) Internal Terraform identifier, equal to the parking policy UUID.
- `uuid` (String) UUID assigned by Turbonomic after creation.
