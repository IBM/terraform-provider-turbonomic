# turbonomic_kubernetes_volume (Data Source)

Retrieves Turbonomic optimization recommendations for a Kubernetes PersistentVolumeClaim (PVC). Kubernetes PVCs are modeled as VirtualVolume entities with a Kubernetes discoveredBy probe. Returns a recommended storage size in GiB when Turbonomic has a SCALE action for the volume.

## Example Usage

```terraform
data "turbonomic_kubernetes_volume" "example" {
  cluster = "<cluster_name>"
  name    = "<pvc_name>"

  # Optional fallback size used when Turbonomic has no SCALE recommendation
  default_size_gib = 10
}
```

## Schema

### Required

- `cluster` (String) Name of the Kubernetes cluster target as it appears in Turbonomic (e.g. `"Kubernetes-mycluster"`). Used to disambiguate PVCs with the same name across clusters.
- `name` (String) Name of the PersistentVolumeClaim as discovered by Turbonomic (e.g. `"pvc-0bab48cf-92c5-4e79-9dd8-62bd4d2fa634"`).

### Optional

- `default_size_gib` (Number) Fallback storage size in GiB to use when Turbonomic has no SCALE recommendation.

### Read-Only

- `action_mode` (String) Mode of the pending action (e.g. `MANUAL`, `RECOMMEND`).
- `action_state` (String) State of the pending action (e.g. `READY`).
- `action_type` (String) Type of the pending action (`SCALE` or empty when no action exists).
- `current_size_gib` (Number) Current storage size in GiB as reported by Turbonomic.
- `entity_uuid` (String) Turbonomic UUID of the VirtualVolume entity.
- `new_size_gib` (Number) Recommended storage size in GiB. Falls back to `current_size_gib`, then `default_size_gib`.
