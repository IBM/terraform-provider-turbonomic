# turbonomic_timespan (Data Source)

Returns Turbonomic time-span schedules (parking schedules), optionally filtered by display name. Reference a timespan UUID in turbonomic_parking_policy via the attach_schedule block.

## Example Usage

```terraform
data "turbonomic_timespan" "all" {}

data "turbonomic_timespan" "business_hours" {
  display_name = "Business Hours"
}
```
