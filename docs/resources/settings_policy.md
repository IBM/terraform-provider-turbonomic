# turbonomic_settings_policy (Resource)

Manages a Turbonomic settings (automation) policy. Settings policies control action automation modes, scaling limits, and utilisation thresholds for a scoped set of entity groups.

## Example Usage

```terraform
# Automation settings policy for VMs scoped to a specific group
resource "turbonomic_settings_policy" "vm_automation" {
  name        = "prod-vm-automation-policy"
  entity_type = "VirtualMachine"
  disabled    = false
  scope_uuids = [turbonomic_group.prod_vms.uuid]
  note        = "Managed by Terraform"

  settings_managers {
    category = "automationmanager"

    settings {
      uuid  = "moveVirtualMachine"
      value = "AUTOMATIC"
    }

    settings {
      uuid  = "resizeVirtualMachine"
      value = "RECOMMEND"
    }
  }

  settings_managers {
    category = "marketsettingsmanager"

    settings {
      uuid  = "resizeTargetUtilizationVcpu"
      value = "70.0"
    }

    settings {
      uuid  = "resizeTargetUtilizationVmem"
      value = "80.0"
    }
  }
}

# Global settings policy (no scope = applies to all VMs)
resource "turbonomic_settings_policy" "vm_global_defaults" {
  name        = "global-vm-defaults"
  entity_type = "VirtualMachine"

  settings_managers {
    category = "automationmanager"

    settings {
      uuid  = "moveVirtualMachine"
      value = "RECOMMEND"
    }
  }
}
```

## Schema

### Required

- `entity_type` (String) Entity type this policy targets. Examples: VirtualMachine, PhysicalMachine, Storage, Container.
- `name` (String) Display name of the settings policy.

### Optional

- `disabled` (Boolean) Set to true to disable the policy. Defaults to false when omitted.
- `note` (String) Free-text note attached to the policy.
- `schedule_uuid` (String) UUID of an existing schedule to attach to this policy.
- `scope_uuids` (List of String) UUIDs of the groups this policy is scoped to. When omitted or empty the policy applies globally.
- `settings_managers` (Block List) List of settings manager blocks. Each block groups settings by manager category. (see [below for nested schema](#nestedblock--settings_managers))

### Read-Only

- `default` (Boolean) True when this is a default policy.
- `id` (String) Internal Terraform identifier, equal to the policy UUID.
- `read_only` (Boolean) True when the policy is system-managed and cannot be deleted or modified.
- `uuid` (String) UUID assigned by Turbonomic after creation.
