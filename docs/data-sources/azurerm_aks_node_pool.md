# turbonomic_azurerm_aks_node_pool (Data Source)

Retrieves Turbonomic optimization recommendations for an Azure AKS node pool. Returns the recommended node count derived from PROVISION/SUSPEND actions on the node VMs that belong to the pool.

## Example Usage

```terraform
data "turbonomic_azurerm_aks_node_pool" "example" {
  cluster_name       = "<cluster_name>"
  name               = "<node_pool_name>"
  default_node_count = 3
}
```

## Schema

### Required

- `cluster_name` (String) Name of the AKS cluster as it appears in Turbonomic.
- `name` (String) Name of the AKS node pool (matched against the `aks-managed-poolName` tag on node VMs in Turbonomic).

### Optional

- `default_node_count` (Number) Fallback node count to use when Turbonomic has no recommendation.

### Read-Only

- `action_mode` (String) Mode of the pending action (e.g. `MANUAL`, `RECOMMEND`).
- `action_state` (String) State of the pending action (e.g. `READY`).
- `action_type` (String) Type of the pending action (`PROVISION`, `SUSPEND`, or empty when no recommendation exists).
- `current_node_count` (Number) Current number of node VMs discovered in this node pool.
- `entity_uuid` (String) Turbonomic UUID of the first matched node VM (representative entity for the node pool).
- `new_node_count` (Number) Recommended node count. Falls back to `current_node_count`, then `default_node_count`.
