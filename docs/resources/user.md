# turbonomic_user (Resource)

Manages a local Turbonomic user account including role assignments and group scope. LDAP users are managed externally and should be read via the turbonomic_user data source. The password attribute is write-only and never stored in state.

## Example Usage

```terraform
resource "turbonomic_user" "observer" {
  username   = "alice"
  password   = var.alice_password
  role_names = ["OBSERVER"]
}

resource "turbonomic_user" "scoped_automator" {
  username          = "bob"
  password          = var.bob_password
  display_name      = "Bob (Scoped Automator)"
  role_names        = ["AUTOMATOR"]
  scope_group_uuids = [turbonomic_group.prod_vms.uuid]
}
```

## Schema

### Required

- `username` (String) Login username. Must be unique. Cannot be changed after creation.

### Optional

- `display_name` (String) Full display name of the user.
- `login_provider` (String) Authentication provider for the user: LOCAL or LDAP. Defaults to LOCAL.
- `password` (String, Sensitive) Password for the user account. Write-only - never stored in state. Required on create for LOCAL users. Ignored for LDAP users.
- `role_names` (List of String) List of role names to assign to the user (e.g. ["OBSERVER", "AUTOMATOR"]). See turbonomic_role data source for available roles.
- `scope_group_uuids` (List of String) List of group UUIDs that define the user's scope. Empty for unscoped (global) users.
- `show_shared_user_sc` (Boolean) Whether to show the shared-user supply chain. Defaults to false.
- `type` (String) User account type: DedicatedCustomer or SharedCustomer. Defaults to DedicatedCustomer.

### Read-Only

- `id` (String) Internal Terraform identifier, equal to the user UUID.
- `uuid` (String) UUID assigned by Turbonomic after creation.
