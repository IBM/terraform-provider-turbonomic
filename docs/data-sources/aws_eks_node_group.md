# turbonomic_aws_eks_node_group (Data Source)

Retrieves Turbonomic optimization recommendations for an AWS EKS node group. Returns the recommended node count derived from PROVISION/SUSPEND actions on the node VMs that belong to the group.

## Example Usage

```terraform
data "turbonomic_aws_eks_node_group" "example" {
  cluster_name         = "<cluster_name>"
  node_group_name      = "<node_group_name>"
  default_desired_size = 3
}
```

## Schema

### Required

- `cluster_name` (String) Name of the EKS cluster as it appears in Turbonomic.
- `node_group_name` (String) Name of the EKS node group (matched against the `eks:nodegroup-name` tag on node VMs in Turbonomic).

### Optional

- `default_desired_size` (Number) Fallback desired node count to use when Turbonomic has no recommendation.

### Read-Only

- `action_mode` (String) Mode of the pending action (e.g. `MANUAL`, `RECOMMEND`).
- `action_state` (String) State of the pending action (e.g. `READY`).
- `action_type` (String) Type of the pending action (`PROVISION`, `SUSPEND`, or empty when no recommendation exists).
- `current_node_count` (Number) Current number of node VMs discovered in this node group.
- `entity_uuid` (String) Turbonomic UUID of the first matched node VM (representative entity for the node group).
- `new_node_count` (Number) Recommended node count. Falls back to `current_node_count`, then `default_desired_size`.
