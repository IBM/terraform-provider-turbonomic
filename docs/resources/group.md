# turbonomic_group (Resource)

Manages a Turbonomic group. Groups are static (fixed UUID list) or dynamic (criteria-based) collections of entities. Use them to scope placement policies, settings policies, and user access.

## Example Usage

### Static group

```terraform
# Static group - members defined by explicit UUID list
resource "turbonomic_group" "prod_vms_static" {
  display_name     = "Prod VMs"
  group_type       = "VirtualMachine"
  is_static        = true
  member_uuid_list = ["vm-uuid-1", "vm-uuid-2", "vm-uuid-3"]
}
```

### Dynamic group  - filter by name regex

```terraform
# Dynamic group - all VMs whose name matches a regex
resource "turbonomic_group" "prod_vms_dynamic" {
  display_name     = "Prod VMs (dynamic)"
  group_type       = "VirtualMachine"
  is_static        = false
  logical_operator = "AND"

  criteria_list {
    filter_entity  = "vm"
    filter_field   = "name"
    operator       = "regex"
    value          = "^prod-.*"
    case_sensitive = false
  }
}
```

### Dynamic group  - filter by tag

```terraform
# Dynamic group - all VMs tagged environment=production
resource "turbonomic_group" "tagged_vms" {
  display_name     = "Tagged Production VMs"
  group_type       = "VirtualMachine"
  is_static        = false
  logical_operator = "AND"

  criteria_list {
    filter_entity = "vm"
    filter_field  = "tag"
    operator      = "equals"
    value         = "environment=production"
  }
}
```

### Dynamic group  - multiple criteria (AND)

```terraform
# Dynamic group - VMs in a specific cluster AND matching a name pattern
resource "turbonomic_group" "cluster_vms" {
  display_name     = "Cluster A Prod VMs"
  group_type       = "VirtualMachine"
  is_static        = false
  logical_operator = "AND"

  criteria_list {
    filter_entity = "vm"
    filter_field  = "cluster"
    operator      = "equals"
    value         = "Cluster-A"
  }

  criteria_list {
    filter_entity  = "vm"
    filter_field   = "name"
    operator       = "regex"
    value          = "^prod-"
    case_sensitive = false
  }
}
```

## Schema

### Required

- `display_name` (String) A user readable name of the group. Cannot be blank. The UTF-8 encoding must be at most 255 bytes.

### Optional

- `criteria_list` (Block List) Criteria for dynamic group membership or filter definition. Each block is one filter criterion. (see [below for nested schema](#nestedblock--criteria_list))
- `group_type` (String) The type of service entities comprising the group.
- `is_static` (Boolean) True if group is static (members defined by member_uuid_list), false if dynamic (members defined by criteria). Defaults to false.
- `logical_operator` (String) Logical operator to be applied across all the criteria used to create dynamic group. Valid values: AND, OR, XOR.
- `member_uuid_list` (List of String) UUID list for members of the group - required if group is static.
- `scope` (List of String) Scope within which the criteria have to be applied to the list of specific entity type.
- `temporary` (Boolean) The Group is only valid for a limited period of time, it will be removed automatically.
- `vendor_ids` (Map of String) The mapping of target identifier to vendor-provided identity of this group, if the group is discovered.

## Notes

- **Static vs dynamic.** Set `is_static = true` and populate `member_uuid_list` for a fixed membership group. Set `is_static = false` (default) and populate `criteria_list` for a dynamic membership group.
- **`filter_type` is resolved at plan time.** When `filter_entity` + `filter_field` are set, `ModifyPlan` computes `filter_type` before apply so the plan has no unknown values.
- **`logical_operator` applies across all criteria.** All criteria in a single group are joined by the same operator (`AND`, `OR`, or `XOR`).
- **`environment_type` and `cloud_type` are computed.** These fields are derived by Turbonomic from the group members and cannot be set in configuration.
- **Import.** Import an existing group using its UUID: `terraform import turbonomic_group.example <uuid>`.
