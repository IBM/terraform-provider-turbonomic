# turbonomic_placement_policy (Resource)

Manages a Turbonomic placement policy. Placement policies control where virtual machines can or cannot run relative to groups of hosts, clusters, or other VMs.

## Example Usage

```terraform
# Bind a group of VMs to a group of hosts (VMs can only run on those hosts)
resource "turbonomic_placement_policy" "bind_to_hosts" {
  name              = "bind-prod-vms-to-prod-hosts"
  type              = "BIND_TO_GROUP"
  enabled           = true
  buyer_group_uuid  = turbonomic_group.prod_vms.uuid
  seller_group_uuid = turbonomic_group.prod_hosts.uuid
}

# Prevent two groups of VMs from running on the same host
resource "turbonomic_placement_policy" "separate_vms" {
  name             = "separate-app-and-db-vms"
  type             = "MUST_NOT_RUN_TOGETHER"
  buyer_group_uuid = turbonomic_group.app_vms.uuid
}

# Merge two clusters so Turbonomic treats them as one
resource "turbonomic_placement_policy" "merge_clusters" {
  name        = "merge-dev-clusters"
  type        = "MERGE"
  merge_type  = "Cluster"
  merge_uuids = [turbonomic_group.cluster_a.uuid, turbonomic_group.cluster_b.uuid]
}
```

## Schema

### Required

- `name` (String) Display name of the placement policy.
- `type` (String) Placement policy type. One of: BIND_TO_GROUP, MUST_NOT_RUN_TOGETHER, MUST_RUN_TOGETHER, MERGE, AT_MOST_N, AT_MOST_N_BOUND, BIND_TO_COMPLEMENTARY_GROUP, BIND_TO_GROUP_AND_LICENSE, EXCLUSIVE_BIND_TO_GROUP.

### Optional

- `buyer_group_uuid` (String) UUID of the consumer (buyer) group. Required for non-MERGE policy types.
- `capacity` (Number) Maximum number of consumer entities allowed per provider entity. Used with AT_MOST_N and AT_MOST_N_BOUND policy types.
- `enable_create_resource_pool` (Boolean) When true, creates a resource pool at the destination during cross-cluster VM moves. Only applicable to MERGE policies with Cluster merge type.
- `enabled` (Boolean) Whether the policy is enabled. Defaults to true.
- `merge_type` (String) Type of merge for MERGE policies. One of: Cluster, DataCenter, DesktopPool, Network, StorageCluster.
- `merge_uuids` (List of String) UUIDs of the groups to merge. Required for MERGE policy type.
- `provider_entity_type` (String) Entity type constraint on the provider group.
- `seller_group_uuid` (String) UUID of the provider (seller) group. Required for non-MERGE policy types.

### Read-Only

- `id` (String) Internal Terraform identifier, equal to the policy UUID.
- `uuid` (String) UUID assigned by Turbonomic after creation.
