# turbonomic_workflow (Data Source)

Returns Turbonomic workflows, optionally filtered by type or display name. Use this data source to look up workflow UUIDs for reference in other resources.

## Example Usage

```terraform
data "turbonomic_workflow" "all" {}

data "turbonomic_workflow" "webhooks" {
  type = "WEBHOOK"
}

data "turbonomic_workflow" "resize_webhook" {
  display_name = "Resize Approval Webhook"
}
```

## Schema

### Optional

- `display_name` (String) Filter results to the workflow whose display name matches exactly. Omit to return all workflows.
- `type` (String) Filter results to workflows of this type (e.g. WEBHOOK, ACTION_SCRIPT). Omit to return all types.

### Read-Only

- `workflows` (Attributes List) List of workflows matching the supplied filters. Empty when no workflows match. (see [below for nested schema](#nestedatt--workflows))
