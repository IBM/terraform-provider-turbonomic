# turbonomic_settings_policy (Data Source)

Returns all Turbonomic settings (automation) policies, optionally filtered by name, entity type, or disabled state. Use this data source to look up policy UUIDs for use in other resources.

## Example Usage

```terraform
data "turbonomic_settings_policy" "all" {}

# Filter by name
data "turbonomic_settings_policy" "by_name" {
  name = "prod-vm-automation-policy"
}

# Filter by entity type
data "turbonomic_settings_policy" "vm_policies" {
  entity_type = "VirtualMachine"
}

# Filter by disabled state - only enabled policies
data "turbonomic_settings_policy" "active" {
  disabled = false
}

# Combine: active VM policies
data "turbonomic_settings_policy" "active_vm_policies" {
  entity_type = "VirtualMachine"
  disabled    = false
}

# Reference UUID from first matching policy
output "policy_uuid" {
  value = length(data.turbonomic_settings_policy.by_name.policies) > 0 ? data.turbonomic_settings_policy.by_name.policies[0].uuid : null
}
```

## Schema

### Optional

- `disabled` (Boolean) Filter results to disabled (true) or enabled (false) policies. Omit to return both.
- `entity_type` (String) Filter results to policies targeting this entity type (e.g. VirtualMachine). Omit to return all entity types.
- `name` (String) Filter results to policies whose name matches this value exactly. Omit to return all policies.

### Read-Only

- `policies` (Attributes List) List of settings policies matching the supplied filters. Empty when no policies match. (see [below for nested schema](#nestedatt--policies))
