# turbonomic_workflow (Resource)

Manages a Turbonomic workflow. Workflows define external integrations (webhooks, action scripts, ServiceNow, Kafka) that are triggered on action lifecycle events. Currently supports WEBHOOK type; other orchestrator types can be referenced via the turbonomic_workflow data source.

## Example Usage

```terraform
resource "turbonomic_workflow" "resize_webhook" {
  display_name       = "Resize Approval Webhook"
  type               = "WEBHOOK"
  action_type        = "RESIZE"
  action_phase       = "PRE"
  entity_type        = "VirtualMachine"
  time_limit_seconds = 300

  webhook_url         = "https://webhook.example.com/approve"
  webhook_method      = "POST"
  webhook_auth_method = "BASIC"
  webhook_username    = "turbo-webhook"
  webhook_password    = var.webhook_password
  webhook_template = jsonencode({
    action  = "{{action.actionType}}"
    entity  = "{{target.displayName}}"
    risk    = "{{action.risk}}"
    savings = "{{action.savings}}"
  })
}

resource "turbonomic_workflow" "notification_webhook" {
  display_name = "Post-Resize Notification"
  type         = "WEBHOOK"
  action_type  = "RESIZE"
  action_phase = "POST"

  webhook_url    = "https://hooks.slack.com/services/example"
  webhook_method = "POST"
  webhook_template = jsonencode({
    text = "Turbonomic completed resize for {{target.displayName}}"
  })
}
```

## Schema

### Required

- `display_name` (String) Human-readable name of the workflow.
- `type` (String) Orchestrator type. Must be WEBHOOK for managed workflows. Other types (ACTION_SCRIPT, SERVICENOW, ACTIONSTREAM_KAFKA, UCSD) are discovered automatically.

### Optional

- `action_phase` (String) Action lifecycle phase: PRE, POST, or REPLACE.
- `action_type` (String) Action type the workflow applies to (e.g. RESIZE, MOVE, SUSPEND). Omit for all action types.
- `description` (String) Optional description of the workflow.
- `entity_type` (String) Entity type the workflow applies to (e.g. VirtualMachine). Omit for all entity types.
- `time_limit_seconds` (Number) Maximum execution time in seconds before the workflow is timed out. Default 600.
- `webhook_auth_method` (String) Authentication method for the webhook: NONE, BASIC, or OAUTH. Default NONE.
- `webhook_method` (String) HTTP method for the webhook call: GET, POST, PUT, DELETE, or PATCH. Default POST.
- `webhook_password` (String, Sensitive) Password for BASIC authentication. Write-only - never stored in state.
- `webhook_template` (String) JSON body template for the webhook request. Supports Turbonomic template variable substitution.
- `webhook_trust_self_signed_certificates` (Boolean) Whether to trust self-signed TLS certificates on the webhook endpoint. Default false.
- `webhook_url` (String) URL of the webhook endpoint. Required when type = WEBHOOK.
- `webhook_username` (String) Username for BASIC authentication.

### Read-Only

- `id` (String) Internal Terraform identifier, equal to the workflow UUID.
- `uuid` (String) UUID assigned by Turbonomic after creation.
