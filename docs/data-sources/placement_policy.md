# turbonomic_placement_policy (Data Source)

Returns all Turbonomic placement policies, optionally filtered by name, type, or enabled state. Use this data source to look up policy UUIDs for use in other resources.

## Example Usage

```terraform
data "turbonomic_placement_policy" "all" {}

# Filter by name
data "turbonomic_placement_policy" "by_name" {
  name = "bind-prod-vms-to-prod-hosts"
}

# Filter by type
data "turbonomic_placement_policy" "merges" {
  type = "MERGE"
}

# Filter by enabled state
data "turbonomic_placement_policy" "active" {
  enabled = true
}

# Combine: enabled BIND_TO_GROUP policies
data "turbonomic_placement_policy" "active_bindings" {
  type    = "BIND_TO_GROUP"
  enabled = true
}

# Reference UUID from first matching policy
output "policy_uuid" {
  value = length(data.turbonomic_placement_policy.by_name.policies) > 0 ? data.turbonomic_placement_policy.by_name.policies[0].uuid : null
}
```

## Schema

### Optional

- `enabled` (Boolean) Filter results to enabled (true) or disabled (false) policies. Omit to return both.
- `name` (String) Filter results to policies whose name matches this value exactly. Omit to return all policies.
- `type` (String) Filter results to policies of this type (e.g. BIND_TO_GROUP, MERGE). Omit to return all types.

### Read-Only

- `policies` (Attributes List) List of placement policies matching the supplied filters. Empty when no policies match. (see [below for nested schema](#nestedatt--policies))
