# turbonomic_azurerm_aks_cluster (Data Source)

Retrieves Turbonomic Smart Parking state and schedule recommendations for an Azure AKS cluster. Returns the current parking state and, if a smart parking schedule is active, the recommended next state.

## Example Usage

```terraform
data "turbonomic_azurerm_aks_cluster" "example" {
  name          = "<cluster_name>"
  default_state = "RUNNING"
}
```

## Schema

### Required

- `name` (String) Display name of the AKS cluster as it appears in Turbonomic (e.g. `"Kubernetes-myakscluster"`).

### Optional

- `default_state` (String) Fallback state to use when the cluster is not found in the Turbonomic parking API.

### Read-Only

- `cloud_provider` (String) Cloud provider of the cluster (e.g. `"AZURE"`).
- `cloud_service_name` (String) Cloud service name of the cluster (e.g. `"AZURE_KUBERNETES_SERVICE"`).
- `current_state` (String) Current parking state of the cluster (`RUNNING`, `STOPPED`, `STARTING`, `STOPPING`, etc.).
- `entity_uuid` (String) Turbonomic UUID of the AKS cluster entity.
- `new_state` (String) Recommended parking state. If a smart parking schedule is active, this differs from `current_state`. Falls back to `current_state`, then `default_state`.
